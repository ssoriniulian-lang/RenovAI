RenovAI v3 — prototip PWA

Features: Romanian, Dutch, French and English; multiple local projects; room surface/volume estimates; paint, tile/floor, adhesive, skirting, wallpaper estimates; project budget; checklist with optional dates and estimated hours; chronological planning view; printable quote; JSON backup export and merge import; offline cache after deployment on HTTPS.

Install/use: deploy this folder as a static website (e.g. GitHub Pages) over HTTPS, open in Chrome on Android, then use browser menu > Install app / Add to Home screen.

Limits: data stays in this browser/device unless exported. Import merges projects and does not replace existing projects. No cloud sync, accounts, camera analysis, AI image measurement, live retail prices, API integrations, VAT/tax calculation, or official contractual quote. Area calculations assume rectangular room geometry and subtract total opening area; check measurements and product specifications before purchase. Wallpaper roll estimate is area-based and does not account for pattern repeat, door/window layout or strip length. Adhesive consumption depends on substrate and trowel; estimate is only a rough allowance. Print/PDF uses browser print dialog.

A backup JSON should be exported before clearing browser data or changing devices.

Verification: see TEST_REPORT.txt for checks and known testing limitations.
